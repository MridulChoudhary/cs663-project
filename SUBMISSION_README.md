# CS663 Course Project — Code Submission

**Faithful Image Super-Resolution for Movie Posters and Digital Artwork**
Mridul Choudhary (23B3933) · Jashanpreet Singh (23B0985)
Repository: https://github.com/MridulChoudhary/cs663-project

This package contains all the code behind the report (`CS663_Faithful_SR_Report.pdf`) and slides, plus the five trained models. Everything under `src/` was written by us; the only pretrained component is the Real-ESRGAN comparator, which is downloaded separately.

## Where each part of the report lives

| Report section | What | Code |
|---|---|---|
| 3.1 Classical interpolation | Nearest, bilinear and bicubic (Keys, a = −0.5) as separable sparse weight matrices; anti-aliased downscale | `src/faithful_sr/models/interpolation.py` (tests: `tests/test_interpolation.py`, Pillow only as an oracle) |
| 3.2 Degradation model y = Q((x∗k)↓s + n) | Bicubic and "mixed" (blur → ↓ → noise → 8-bit → JPEG), seeded per image | `src/faithful_sr/data/degradation.py`, `configs/degradation.yaml` |
| 3.3 FSRNet (ours) and SRCNN | 8 residual blocks, sub-pixel ×3, global bicubic skip, zero-init last conv; SRCNN 9-5-5 | `src/faithful_sr/models/cnn.py` |
| 3.3 Training | L1/MSE loss, Adam, cosine LR, 30k iterations, exact resume (RNG state), best/latest checkpoints | `src/faithful_sr/training/train.py`, `training/checkpointing.py`, `configs/train_fsrnet_x3.yaml`, `configs/train_srcnn_x3.yaml`, `scripts/train_model.py` |
| 3.4 Real-ESRGAN comparator | x4plus via spandrel; 4× output resized to 3×/6×; tiled | `src/faithful_sr/inference/learned.py`, `scripts/download_weights.py` |
| 3.5 Tiled inference and 6× strategies | Seam-free overlapping tiles; 3×→bicubic 2×, 3×→3×→↓ | `src/faithful_sr/inference/tiling.py`, `inference/upscale.py`, `inference/sizing.py` |
| 4 Datasets | DIV2K + poster splits (source-level, seeded), duplicate removal, quality screen, LR/HR generation, patch extraction | `src/faithful_sr/data/prepare.py`, `data/manifest.py`, `data/patches.py`, `configs/dataset.yaml`, `scripts/prepare_dataset.py` |
| 4 Annotations | Poster category tags and hand-drawn text/face regions | `data/poster_tags.csv`, `data/rois.json` |
| 4 Metrics | PSNR/SSIM on BT.601 luma (matches scikit-image), RGB-PSNR, edge-PSNR, overshoot, LPIPS | `src/faithful_sr/evaluation/metrics.py` |
| 4 Region analysis | Text/face/edge/texture/flat regions | `src/faithful_sr/evaluation/region_analysis.py` |
| 4–5 Benchmark (E1–E8, A1–A3) | All methods × scales × degradations, resumable; runtime and memory | `src/faithful_sr/evaluation/benchmark.py`, `configs/eval.yaml`, `scripts/evaluate_model.py` |
| 5 Statistics | Paired per-image differences, 95% bootstrap CIs, win rates | `src/faithful_sr/evaluation/report.py`, `scripts/build_report.py` |
| 5 Figures, tables, report, slides | Every number is computed from the result CSVs | `scripts/make_figures.py`, `scripts/build_report.py`, `scripts/export_deck_numbers.py`, `scripts/build_deck.js` |
| GUI demo | Gradio before/after slider | `src/faithful_sr/gui/app.py`, `scripts/launch_gui.py` |
| Colab run | The exact notebook used for training and evaluation | `notebooks/colab_train_evaluate.ipynb` (generated by `notebooks/make_colab_notebook.py`), `scripts/colab_setup.py` |
| Decisions and results log | Design decisions and the status of every experiment | `docs/decisions.md`, `docs/experiments.md`, `docs/methodology.md` |

## Running it

```bash
pip install -r requirements.txt            # + requirements-pretrained.txt for Real-ESRGAN/LPIPS
python -m pytest -q                        # 92 tests, CPU, about 20 s
python scripts/upscale.py --help           # upscale your own image with any method
python scripts/launch_gui.py               # GUI
```

The full pipeline (dataset preparation → training → benchmark) runs on a free Colab GPU through `notebooks/colab_train_evaluate.ipynb`; see `README.md`.

**Not included:** the DIV2K images (downloaded automatically by the notebook) and the poster images. They're kept out of the repository and this package because many posters show franchise characters.
